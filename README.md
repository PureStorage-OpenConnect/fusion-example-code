# Everpure Fusion Example Code and Script Repository

A collection of example code and scripts for Everpure Fusion automation.

## Contributing

Thanks for your interest in improving this repository collection.

This project welcomes issues and pull requests that improve on existing and newly submitted example code quality, safety, and support.

## Contributor requirements

By participating in this project, contributors are expected to follow the Everpure Open Connect Code of Conduct: [https://github.com/PureStorage-OpenConnect/Code-of-Conduct](https://github.com/PureStorage-OpenConnect/Code-of-Conduct)

External contributors must accept Everpure's Contributor License Agreement (CLA) before their contributions can be merged.

## Before you start

1. Check existing issues and pull requests to avoid duplicate work.
2. For larger changes, open an issue first and describe the proposed behavior, user impact, and test plan.

## What makes a good contribution

- Follow the [Code of Conduct]((https://github.com/PureStorage-OpenConnect/Code-of-Conduct](https://github.com/PureStorage-OpenConnect/Code-of-Conduct)) and the contributor requirements above.
- Keep user-facing behavior clear and bounded.
- Preserve safe defaults. .
- Avoid committing secrets, array tokens, customer data, internal hostnames, or auto-generated credentials files.
- Update documentation when setup, flags, tools, limitations, or user-visible behavior changes.

## Support

For issues and feature requests, open a GitHub issue in this repository.
The contents of this repository are considered Open Source and in the public domain, therefore, there is no official support provided by Everpure, Inc.
